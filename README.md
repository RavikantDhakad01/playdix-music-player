# 🎵 playdix – Web Music Player

> 🎧 **playdix** is a responsive, web-based music player inspired by modern streaming platforms.  
> It offers a **clean, modern UI** and a **smooth playback experience**, built purely with  
> **HTML, CSS, and Vanilla JavaScript**.

---

## 🚀 Features

- 🎶 Play / Pause music
- ⏭️ Next & Previous track controls
- 📃 Dynamic song list loaded from JSON
- ⏱️ Live track duration & progress indicator
- 🎚️ Click-to-seek progress bar
- 📱 Fully responsive layout (mobile & desktop)
- 🍔 Hamburger menu for small screen
- 🎧 Animated music player indicator
- 🖤 Modern dark-themed UI

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & responsiveness  
- **JavaScript (Vanilla)** – Logic & audio handling  
- **Web Audio API**

---

## 🌐 Live Project

🚀 **Live Demo:**  
👉 https://playdix.netlify.app/

---

## ⚙️ How It Works

- Songs are dynamically fetched from `songs.json`
- Audio playback is managed using JavaScript’s `Audio` object
- Playback progress updates in real time
- UI adapts seamlessly across screen sizes
